# 前端项目

> Vue 3 + Vite + TypeScript + Naive UI + UnoCSS

## 状态: MVP 已实现

页面:
- `/login` — 登录/注册页
- `/dashboard` — 管理面板首页

## 启动

```bash
cd frontend && pnpm install && pnpm dev
```

## 技术栈

- Vue 3.5 / Vite 6 / TypeScript / Naive UI / UnoCSS / Pinia / Axios
