# 项目架构

## 系统全景

```
┌─────────────────────────────────────────────────┐
│                   用户层                          │
├──────────┬──────────┬──────────┬────────────────┤
│  Web App │ 小程序   │ Flutter  │  (各端独立部署) │
│  Vue3+TS │ 待实现   │ 待实现   │                │
├──────────┴──────────┴──────────┴────────────────┤
│                   API 网关                        │
├─────────────────────────────────────────────────┤
│              后端服务 (Go + Gin)                  │
│         鉴权 / 用户管理 / 会话管理               │
├─────────────────────────────────────────────────┤
│              知识库 (Markdown 文件)               │
│         故事背景 / 技术文章 / 规则设定           │
└─────────────────────────────────────────────────┘
```

## 各端职责

| 模块 | 技术栈 | 状态 | 职责 |
|------|--------|------|------|
| 后端 | Go + Gin | 开发中 | 鉴权、用户管理、API |
| 前端 | Vue 3 + Vite + TS + UnoCSS | 开发中 | Web 页面展示 |
| 小程序 | 待定 (uni-app) | 待实现 | 小程序展示 |
| Flutter | Dart + Flutter | 待实现 | 客户端展示 |
| 知识库 | Markdown + 多层索引 | 维护中 | 内容存储 |
