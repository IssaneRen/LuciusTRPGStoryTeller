# CoC 7th Edition 战斗规则

## 核心机制

### 技能检定

D100 骰点 vs 技能值:
- 大成功: 01
- 极难成功: ≤ 技能值/5
- 困难成功: ≤ 技能值/2
- 成功: ≤ 技能值
- 失败: > 技能值
- 大失败: 96-100 (技能≤50时 100, 技能>50时 96-100)

### 战斗回合

每回合每个角色可执行一个动作:
- 近战攻击
- 射击 (枪械)
- 施法 (魔法)
- 闪避
- 逃跑

#### 先攻顺序
DEX 高者先行动。DEX 相同则比 INT。

### 近战攻击

1. 攻击者掷 D100 vs 格斗技能
2. 防御者可选择: 闪避 或 反击
   - 闪避: D100 vs 闪避技能 (DEX/2)
   - 反击: D100 vs 格斗技能 (但本回合放弃攻击)
3. 对抗判定:
   - 攻击极难 vs 防御困难 → 攻击命中
   - 攻击困难 vs 防御普通 → 攻击命中
   - 攻击成功 vs 防御失败 → 攻击命中
   - 双方同等级成功 → 攻击方主动优势，命中
4. 命中后掷伤害骰 + 伤害加值(DB)

### 枪械射击

1. 射手掷 D100 vs 枪械技能
2. 目标无法闪避子弹 (除非事先声明躲避，且意识到攻击)
3. 距离修正:
   - 近距 (≤基础射程): 无修正
   - 中距 (≤2x射程): 困难难度
   - 远距 (≤4x射程): 极难难度
4. 连发规则: 每额外发子弹 +1 命中骰 (最多=枪械每回合射击数)
5. 命中后掷伤害骰，无 DB 加成
6. 贯穿: 若伤害骰取最大值，贯穿(对后方目标额外一次命中判定)

### 魔法

1. 施法者掷 D100 vs POW×5 (或特定法术技能)
2. 消耗 MP (魔力值)
3. 目标可用 POW 对抗 (D100 vs POW×5)
4. 常见法术类型:
   - 直接伤害: 消耗 X MP，造成 XD6 伤害
   - 精神攻击: 对抗 POW，失败则 SAN 损失
   - 束缚: 对抗 POW，失败则无法行动 1D4 回合

### 伤害与生命

- HP = (CON + SIZ) / 10 向下取整
- 重伤: 单次伤害 ≥ HP/2 → 昏迷检定 (CON×5)
- 濒死: HP = 0 → 每回合流血 1HP，CON×5 检定保持意识
- 死亡: HP = -HP最大值

### 伤害加值 (DB) 和体格

| 2-64 | -2 | -2 |
| 65-84 | -1 | -1 |

| 445-524 | +5D6 | 6 |

### 护甲

伤害 = 伤害骰结果 - 护甲值 (最低0)

## 角色属性

### 调查员 (PC)

```
STR: 力量 (3D6×5)
CON: 体质 (3D6×5)
SIZ: 体型 (2D6+6)×5
DEX: 敏捷 (3D6×5)
APP: 外貌 (3D6×5)
INT: 智力 ((2D6+6)×5)
POW: 意志 (3D6×5)
EDU: 教育 ((2D6+6)×5)
HP: (CON+SIZ)/10
MP: POW/5
SAN: POW
```

### 技能默认值

- 格斗(斗殴): 25%
- 闪避: DEX/2
- 枪械(手枪): 20%
- 枪械(步枪/霰弹枪): 25%
- 枪械(冲锋枪): 15%

## 难度评估

模拟 N 次战斗后，按 PC 存活率评分:
- 90%+ 存活 → 简单 (1星)
- 70-89% 存活 → 较易 (2星)
- 50-69% 存活 → 中等 (3星)
- 30-49% 存活 → 困难 (4星)
- <30% 存活 → 极难 (5星)
