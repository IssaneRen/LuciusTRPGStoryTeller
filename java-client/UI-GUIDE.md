# CoC 7th 战斗模拟器 UI 使用指南

## 快速开始

### 1. 启动应用

```bash
cd java-client
./run-ui.sh
```

或手动运行：

```bash
./gradlew run
```

### 2. 界面布局

主窗口分为左右两个区域：

**左侧面板（配置区）**
- 调查员配置：管理 PC 角色列表
- 敌人配置：管理怪物/NPC 列表
- 模拟控制：设置模拟次数并开始

**右侧面板（结果区）**
- 结果统计：存活率、平均回合数、难度评级
- 战斗日志：详细战斗过程记录

## 功能说明

### 添加调查员

1. 点击"添加调查员"按钮
2. 在弹出对话框中输入：
   - 名称：角色名称
   - 属性：STR、CON、SIZ、DEX、INT、POW（15-99）
   - 技能：格斗、手枪、步枪（0-99）
   - 武器：从下拉列表选择
   - 护甲：0-10
3. 点击"确认"保存

**小技巧：** 点击"随机生成属性"按钮可以快速生成符合 CoC 7th 规则的随机属性（3D6×5）

### 添加敌人

**方式一：手动添加**
1. 点击"添加怪物"按钮
2. 配置流程同添加调查员

**方式二：使用预设**
1. 点击"预设怪物"按钮
2. 从下拉菜单选择：
   - 深潜者（中等难度）
   - 修格斯幼体（高难度）
   - 食尸鬼（中低难度）

### 开始模拟

1. 至少添加 1 个调查员和 1 个敌人
2. 设置模拟次数（默认 100，建议 100-1000）
3. 点击"开始模拟"按钮
4. 等待模拟完成（大量模拟时可能需要数秒）

### 查看结果

**统计数据（右上角卡片）**
- 存活率：PC 方的胜率百分比
- 平均回合数：战斗平均持续回合数
- 难度评级：★ ~ ★★★★★（简单 ~ 致命）

**战斗日志（右下方）**
- 绿色文字：成功事件（命中、胜利等）
- 红色文字：危险事件（伤害、失败等）
- 黄色文字：警告事件
- 灰色文字：常规信息

### 导出日志

1. 点击"导出日志"按钮
2. 日志自动保存到 `logs/battle_log_YYYYMMDD_HHMMSS.txt`
3. 日志中会显示导出路径

## 常见问题

### Q: 为什么点击"开始模拟"没反应？

A: 请确保：
1. 至少添加了 1 个调查员
2. 至少添加了 1 个敌人
3. 模拟次数 > 0

### Q: 日志太多，如何清理？

A: 点击"清空日志"按钮可清空当前日志显示。历史日志文件不会被删除。

### Q: 模拟速度慢怎么办？

A: 
- 减少模拟次数（如从 1000 降到 100）
- 减少角色数量
- 模拟在后台运行，不会卡死界面

### Q: 能否保存角色配置？

A: 当前版本暂不支持，后续版本会添加。

### Q: 闪避技能如何设置？

A: 闪避由 DEX 属性自动计算（DEX / 2），无需手动设置。

## 技术信息

- Java 版本：17+
- UI 框架：Swing + FlatLaf 3.6
- 主题：FlatDarkLaf（现代化暗色主题）
- 线程模型：SwingWorker（模拟在后台线程执行）
